# shell-practice

Practice the command line and Git on your own, at your own pace.
Course: *Git, Python Environments & Coding Best Practices* (MSA-DATB07-03).

## Get it

In Git Bash (Windows) or the Terminal (macOS), in your course folder:

```bash
git clone https://github.com/msa-datb07-git/shell-practice.git
cd shell-practice
```

## How it works

- `EXERCISES.md`: 33 short exercises, from "where am I?" to a merge conflict.
  Do them in order; each level uses the previous ones.
- `SOLUTIONS.md`: the commands and the answers. Try first, then check.
- `playground/`: the folder tree the exercises work on (weather stations).
  `playground/tmp/` is yours: create and delete anything there.

Broke something? `git restore .` brings back every file of the repository as it was
(files you created in `playground/tmp` are not touched). Or delete the folder and clone again.
